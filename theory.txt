Q2 -  Describe the Git workflow your team should adopt to prevent this from happening
again. Name at least two Git commands your team should use as part of this workflow and
explain the role of each command.

=>Recommended Git workflow:

The team should use a feature-branch workflow instead of directly making changes on the main branch. 
Each team member should create a separate branch for their work, make changes, and test them before creating a Pull Request.
 The changes should be reviewed and merged into the main branch only after they are working correctly.

->Git commands:

1. git checkout -b feature-name
This command creates a new branch and switches to it. Team members can use it to work on their feature without affecting the main branch.

2. git pull
This command downloads and integrates the latest changes from the remote repository, helping the team keep their local branch updated.

3. git push
This command uploads the committed changes from the local branch to the remote repository so that other team members can review them.

->This workflow reduces the risk of incomplete or untested code breaking the main branch.

Q4 - Explain how Bootstrap's grid class system works to produce this responsive layout.
Write the Bootstrap class combination you would apply to the article column div, and explain
what each class in the combination controls.

=>Bootstrap uses a 12-column grid system. To display articles in 3 columns on desktop and 1 column on mobile,
 we can use the following Bootstrap classes:

<div class="row">
    <div class="col-12 col-md-4">Article 1</div>
    <div class="col-12 col-md-4">Article 2</div>
    <div class="col-12 col-md-4">Article 3</div>
</div>

->Explanation:

- row: Creates a horizontal row for the columns.
- col-12: Makes each article occupy all 12 columns on small/mobile screens, so they appear as one column.
- col-md-4: From medium-sized screens and above, each article occupies 4 out of 12 columns.
  Therefore, 3 articles fit in one row (4 + 4 + 4 = 12).

->This creates a responsive layout without writing custom media query CSS.

Q6 -  Explain why the program crashes on an empty string input and describe the check
your pointer-based solution must perform before dereferencing the pointer. How does traversing
a string using a pointer differ from traversing it using array index notation, and which approach
makes the empty-input bug easier to catch?

=>A pointer is a variable that stores the memory address of another variable.

Example:

int num = 10;
int *ptr = &num;

printf("Value of num: %d\n", num);
printf("Address of num: %p\n", (void*)&num);
printf("Value using pointer: %d\n", *ptr);

*ptr = 20;

printf("Updated value of num: %d\n", num);

->Explanation:

- &num gives the memory address of num.
- ptr stores the address of num.
- *ptr accesses the value stored at that address.
- When we use *ptr = 20, the value of num is changed to 20.
